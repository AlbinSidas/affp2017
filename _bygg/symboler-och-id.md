# Symboler och ID-konventioner
## Standard för alla bilder och all numrering i föreningen

---

## Symboler

Samma symboler i alla övningsbilder, i alla åldrar, i alla dokument.

| Symbol | Betyder |
|---|---|
| Mörkblå cirkel | Spelare, anfallande lag |
| Kopparfärgad cirkel | Försvarare, motståndare |
| Grön cirkel | Målvakt |
| Vit liten cirkel | Boll |
| Kopparfärgad triangel | Kon |
| Heldragen pil | Löpning utan boll |
| Streckad pil | Passning |
| Vågig linje med pil | Föra bollen |
| Svart rektangel | Mål |
| Streckad grön linje | Zon- eller yttmarkering |

Måttangivelser skrivs uppe till vänster i bilden, i grönt.

---

## Övnings-ID

Format: **prefix + siffra**

| Prefix | Kategori |
|---|---|
| `A` | Föra bollen, bollmästeri i rörelse |
| `B` | 1 mot 1, finter, försvarsteknik |
| `C` | Första touch, scanning, vändningar |
| `D` | Passningsspel och understöd *(reserverat, från 7 mot 7)* |
| `E` | Presspel och återerövring *(reserverat, från 9 mot 9)* |
| `MV` | Målvakt |
| `T` | Testövning. Numret följer testdagens ordning: T1–T6. Flera är testvarianter av träningsövningar (T1 av A3, T4 av C2, T6 av C1) men har egna kort eftersom protokollet skiljer sig. |
| `G` | Spelformer och matchliknande spel. G1 småbanor, G2 femmannaspel, G3 hel plan. |
| `ANK` `KAR` `TRK` `RON` | Struktur och rutin, inte enskild övning |

### Tre regler

1. **Ett ID betyder samma sak för alltid.** A3 är Grindar i hela klubben, i alla åldrar, i alla år.
2. **Ett ID återanvänds aldrig.** Tas en övning bort blir numret ledigt men används inte igen, så att gamla säsongsplaner fortfarande går att läsa.
3. **Förbättringar skrivs in i den befintliga rutan.** Koden ändras aldrig. Alla lag får förbättringen automatiskt.

### Lägga till en övning

Skicka förslag till fotbollsutvecklaren med: uppställning, genomförande, två till tre coachpunkter, och förslag på nivåanpassning. Nya ID tilldelas i november.

## Pass-ID

Inom en säsongsplan: `P1` till `P26`.

I klubbsammanhang skrivs det fullständigt:

```
2017-P9 / 2026-höst / P05
[årskull]  [säsong]   [pass]
```

---

## Filnamn

Säsongsplaner: `04-sasongsplan-[säsong].html`, t.ex. `04-sasongsplan-var-2027.html`.

Inga mellanslag, inga versaler, inga diakriter i filnamn — använd `host` och `var`.

## Principer och positioner

Spelidéns tre ord skrivs versalt när de refereras: **BOLL**, **MOD**, **PRESS**.

Positionsnumren 1–11 enligt `01-sa-spelar-vi.md`. Ett nummer betyder samma sak i hela klubben, från 5 mot 5 till A-truppen.
